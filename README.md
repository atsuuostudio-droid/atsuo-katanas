# Atsuo Katanas

Kit de fabrication des katanas add-on du serveur FiveM **Atsuo RP** (ESX Legacy + ox_inventory).

| Fichier / dossier | Rôle |
|---|---|
| `1_PROCEDURE_Katana_Atsuo.docx` | Procédure complète, de l'image à l'arme en jeu |
| `2_MESSAGE_A_COLLER.txt` | Message à envoyer pour lancer une nouvelle arme |
| `3_scripts_blender/` | Placement en main (`katana_comme_machette.py` v3) |
| `4_modele_ressource/` | Ressource du Katana Kin (validée en jeu), à copier |
| `5_outils_claude/` | Scripts de fabrication (monture 3D, textures, Sollumz) — voir `README_CLAUDE.md` |
| `6_REGISTRE_ARMES.txt` | Slots / orders déjà pris (prochaine arme : 193 / 423) |
